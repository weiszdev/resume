# Resume — Jonathan C Weisz

Public copy of the current resume, in two forms:

| File | Purpose |
|------|---------|
| `resume.md` | Source of truth — plain markdown, easy to edit |
| `resume.html` | Styled, print-ready version (open in a browser, Cmd+P → Save as PDF) |

`resume.html` is self-contained: inline CSS, light/dark aware, and print styles that
drop to a clean 0.4in-margin page. Fonts load from Google Fonts with system fallbacks.

Contact details are intentionally omitted from this public copy.

Edit `resume.md` first, then mirror the change into `resume.html`.
